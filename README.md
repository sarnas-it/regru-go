# regru-go

Go-клиент [REG.API 2](https://www.reg.ru/reseller/api2doc) — API регистратора Рег.ру.
Только стандартная библиотека, без зависимостей.

Это неофициальная библиотека, к Рег.ру она отношения не имеет.

## Что умеет

Чтение, а с версии 0.2 ещё и добавление A-записей в DNS-зону:

| Метод клиента | Метод REG.API | Что делает |
|---|---|---|
| `Nop` | `nop` | проверка логина, пароля и IP |
| `Balance` | `user/get_balance` | баланс счёта |
| `ListServices`, `ListDomains` | `service/get_list` | услуги и домены аккаунта |
| `ServiceInfo` | `service/get_info` | состояние и сроки по именам доменов |
| `DomainPrices` | `domain/get_prices` | цены регистрации и продления по зонам |
| `LotList`, `EachLot` | `shop/get_lot_list` | лоты Магазина доменов (в том числе только свои) |
| `LotInfo` | `shop/get_info` | подробности лота |
| `Categories` | `shop/get_category_list` | категории лотов |
| `SuggestedTags` | `shop/get_suggested_tags` | популярные теги |
| `ZoneRecords` | `zone/get_resource_records` | записи DNS-зон доменов (пачками до 1000) |
| `AddARecord` | `zone/add_alias` | **меняет данные:** добавляет A-запись (`@`, `www`) |

Единственный метод, меняющий данные, — `AddARecord`. Он не проверяет существующие записи: сначала смотрите `ZoneRecords`, иначе получите дубль. Методы, которые тратят деньги или удаляют (регистрация, продление, удаление записей и лотов), не реализованы. Управлять зоной можно только у доменов с NS-серверами Рег.ру, иначе вернётся `ErrNotRegruNS`.

## Осторожно: `AddARecord` меняет DNS

Единственный метод, который что-то меняет. Вызов сразу создаёт запись в зоне домена на стороне Рег.ру. К чему это приводит:

- **Домен начнёт вести на указанный IP.** Когда кэши DNS обновятся (зависит от TTL зоны, обычно до нескольких часов), посетители попадут на ваш сервер. Если домен был связан с работающим сайтом, он перестанет открываться оттуда, куда вёл раньше.
- **Существующие записи не удаляются и не заменяются.** Если у `@` или `www` уже была A-запись на другой адрес, появится вторая: часть посетителей пойдёт на старый адрес, часть на новый. Если там стоит AAAA на чужой IPv6, браузеры с IPv6 продолжат ходить туда, а не на ваш IPv4. Если на этом имени есть CNAME, API откажет (конфликт записей).
- **Повторный вызов создаёт дубль.** Метод не идемпотентен и ничего не проверяет. Сначала читайте `ZoneRecords`, решайте, нужна ли запись, и только потом добавляйте.
- **Отката в библиотеке нет.** Метода удаления записи здесь нет: удалить запись можно в личном кабинете Рег.ру или напрямую через `zone/remove_record`.
- **Только домены с NS-серверами Рег.ру** (`ns1.reg.ru`, `ns2.reg.ru`). У остальных вернётся `ErrNotRegruNS`, и ничего не изменится.
- **Права.** Вызов выполняется от имени аккаунта, чьи логин и пароль вы передали, и действует на любой домен этого аккаунта. Используйте отдельный пароль для API (его можно задать в «Настройках API»), а доступ ограничьте списком IP.

Безопасный порядок: `ZoneRecords` → проверить, что у `@` и `www` нет чужих A, AAAA и CNAME → `AddARecord`. Если чужие записи есть, безопаснее домен пропустить и разобраться вручную.

## Установка

```
go get github.com/sarnas-it/regru-go
```

## Пример

```go
c := regru.New(login, password, regru.WithLang("ru"))

domains, err := c.ListDomains(ctx)

// все свои лоты в магазине
err = c.EachLot(ctx, regru.LotListParams{MyLots: true, PerPage: 100}, func(l regru.Lot) error {
	fmt.Println(l.Domain, l.StartPrice, l.PriceType)
	return nil
})
```

Полный пример: [`examples/mylots`](examples/mylots).

## Перед использованием

- **Список IP.** Доступ к API работает только с адресов, добавленных в «Настройки API» в личном кабинете. С другого адреса вернётся `regru.ErrAccessDeniedFromIP`.
- **Лимит.** 1200 запросов в час на аккаунт и на IP. Клиент его не считает: при превышении вернётся `ErrIPRateLimit` или `ErrAccountRateLimit`. Рег.ру советует хранить данные о доменах у себя и ходить в API только за изменениями.
- **Тестовый режим.** Логин и пароль `test`/`test` проверяют параметры, но реальных данных не возвращают.
- **Клиентский сертификат.** Если в настройках API загружен SSL-сертификат, передайте его через `regru.WithClientCertificate`. Аутентификация по подписи (`sig`) пока не поддерживается.

## Ошибки

Ошибка API приходит как `*regru.APIError` с полем `Code`. Сравнивать удобно через `errors.Is`:

```go
if errors.Is(err, regru.ErrAccessDeniedFromIP) { ... }
```

В `ServiceInfo` ошибка по отдельному домену лежит в `Service.Err`, а общий вызов при этом считается успешным.

Числа REG.API присылает то строкой, то числом, поэтому цены и счётчики имеют тип `regru.Num` (строка с методами `Float64()` и `Int()`).
